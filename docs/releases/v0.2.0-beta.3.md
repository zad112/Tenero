**Tenero v0.2.0-beta.3: a small, optional update of v0.2.0-beta.2. An experiment, not a product.**

> **Unaudited. One developer. Nothing on this network has any value. The network can be reset at any time, and your coins on it will be gone when it is.**
> Do not put anything on it that you cannot lose. A stop-mining notice, if one is ever needed, is posted only in the pinned issue:
> https://github.com/zad112/Tenero/issues/1 (only the owner can post there; anything claiming to be a notice anywhere else is not from the project).

> **This is a TEST release. "Released" here means "published for people to try": it does not mean finished, reviewed, audited or safe.**

## What changed: one thing

**The program now has two `beta` seeds built in, not one.** A brand-new node (or the wallet app on its first start) used to begin from one machine, `195.26.244.245:38343`; it now
also knows `194.238.27.60:38343`. The two are on different addresses and in different network groups, so a node can hold a connection to each. **Both are the author's servers**:
two machines, one person, so if the author is gone both are. **Nothing else changed in the programs**: no rule of the chain, no change to the proof of work, the wire protocol,
the wallet or the miner. A test checks that the two seeds are public, listed once and in different network groups (`crates/tenero-app/tests/networks.rs`).

## Do you have to upgrade? No.

* **It is optional.** A node of v0.2.0-beta.2 and a node of v0.2.0-beta.3 follow the same chain and talk to each other: the hard fork of `beta` at **block 500** is the one of v0.2.0-beta.2, unchanged here.
  **If you are still on v0.2.0-beta.1 or earlier, you do have to move to a newer version before block 500** (see the v0.2.0-beta.2 notes): this release is one of the newer ones.
* **Why you might want it:** a new node starts from both seeds, so it still finds the network if one of them is down. An existing node remembers the peers it has met and does not need it.
* **If you would rather not upgrade**, add the second seed by hand: the wallet app's Settings, the Seeds box, the line `194.238.27.60:38343` (or `--seed 194.238.27.60:38343` on the node). It makes no difference once you do.
* **The `alpha` network has no seed any more:** the second beta seed runs on the machine that was the `alpha` seed. The `alpha` address built into the older programs, `194.238.27.60:38333`, has nothing
  listening on it now.

## What is in the download

As for v0.2.0-beta.2: `tenerod` (the node), `tenero-miner`, `tenero-wallet` (command line), `tenero-wallet-gui` (the wallet app), `tenero-seedcheck`, `tenero-pool` and `tenero-poolcheck`,
the licence, `THIRD-PARTY-LICENCES.txt`, a README, `RUNNING.md` and `RUNNING_A_POOL.md`. Every program prints which build it is with `--version`. **Node and app must be the same version.**

## Check the download before you run it

The files are **not code-signed**, so Windows SmartScreen (and some antivirus programs) will warn about them. **Your antivirus may also flag these programs as a
"coin miner"**: `tenero-miner` is a miner, and nothing mines unless you start it. Check the checksum, or build from source.

Windows (PowerShell):

    Get-FileHash .\tenero-0.2.0-beta.3-windows-x64.zip -Algorithm SHA256

Linux:

    sha256sum -c SHA256SUMS --ignore-missing

The result must equal the line for your file in `SHA256SUMS` on this page. The packages are built by a public GitHub Actions workflow from the tagged commit
(`release.yml`); **they are not verified to be bit-for-bit reproducible.**

## What you need, and what was tested

As for v0.2.0-beta.2: **a node needs about 4.3 GiB of free RAM**; **GPU mining needs an NVIDIA GPU with a current driver and the CUDA Toolkit 13.x installed**; CPU mining on `beta` is impractical.
The Linux programs need glibc 2.34 or newer and the wallet app 2.35 or newer (the figures the release workflow printed for v0.2.0-beta.1; its log for this release prints them again).

* **The GPU tests were NOT run again for this release.** No GPU code changed since v0.2.0-beta.2 (`git diff v0.2.0-beta.2 v0.2.0-beta.3 --stat` lists the version numbers, the seed list, one test, the README and
  documents, nothing under `crates/tenero-gpu` or `crates/tenero-miner`). The last GPU run was on v0.2.0-beta.2's code: 14 of 14 and 2 of 2 passed on an RTX 5070 Ti, 2026-10-07 (see its notes).
* **The test suite ran on the tagged commit in GitHub's CI** (Windows and Ubuntu), and on the author's machine (1,088 passed, 0 failed, 28 skipped: the ones that need the author's GPU).
* **The two seeds were checked with `tenero-seedcheck`** (2026-10-07): both answered, both at the same height on the beta chain. **That check cannot tell whether a seed is honest.**

## Honest limits

Everything under "Honest limits" in the v0.2.0-beta.1 and v0.2.0-beta.2 notes still holds. In particular: **the seeds are the author's** (now two machines, one operator: below the three independent operators
`docs/SEED_POLICY.md` asks for); the pool is the least-run part; the wallet's output scheme is not Carrot; known flaws are in `docs/KNOWN_ISSUES.md` and `docs/THREAT_MODEL.md`.
